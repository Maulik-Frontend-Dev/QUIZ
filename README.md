# 🎯 Quiz Master – Interactive Quiz Web Application

## 📌 Overview

Quiz Master is a fully responsive and interactive quiz web application built using **HTML, CSS, and JavaScript**.
The project includes a complete quiz system with:

* Dynamic question handling
* Difficulty-based gameplay
* Real-time leaderboard
* Achievement badges
* Analytics tracking
* Persistent localStorage data
* Fully responsive UI for all devices

This project is designed to be **portfolio-ready**, **resume-worthy**, and deployable as a real-world frontend application.

---

# 🚀 Features

## 🧠 Quiz System

* Dynamic quiz questions from `quizdata.js`
* Random 10-question quiz generation
* Questions displayed one-by-one
* Automatic next-question navigation
* Difficulty-based timers:

  * Novice → 45 seconds
  * Expert → 30 seconds
  * Genius → 15 seconds
    
* Real-time score tracking
* Correct/Wrong answer highlighting
* Smooth transitions and animations

---

## 🏆 Leaderboard System

* Persistent leaderboard using `localStorage`
* Stores:

  * Player name
  * Score
  * Percentage
  * Difficulty level
    
* Automatically sorted by highest score
* Real-time updates after every quiz

---

## 🎖️ Achievement & Badge System

* Dynamic badge unlocking
* Real-time progress tracking
* Locked/unlocked badge states
* Achievement conditions such as:

  * First quiz completed
  * 100% score
  * Win streaks
  * Difficulty mastery
  * Top leaderboard ranking
* Badge data stored permanently using `localStorage`

---

## ⚙️ Settings & Analytics

* Dynamic user statistics
* Quiz history tracking
* Accuracy percentage
* Total quizzes played
* Highest score
* Fastest answer time
* Most-used difficulty
* Reset functionality:

  * Reset leaderboard
  * Reset badges
  * Reset history
* Theme/sound preferences support
